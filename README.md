# Cyber Detective

![Status](https://img.shields.io/badge/status-concluído-brightgreen) ![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python) ![Flet](https://img.shields.io/badge/Flet-Framework-purple) ![GitHub](https://img.shields.io/badge/GitHub-Repository-black?logo=github)

Aplicação interativa desenvolvida em Python utilizando o framework **Flet**, com temática de investigação e cibersegurança.

---

## Sobre o Projeto

O **Cyber Detective** foi desenvolvido como uma atividade prática realizada em sala de aula.

A aplicação simula uma investigação de um incidente de segurança, onde o usuário precisa analisar evidências, investigar informações, escolher hipóteses e chegar a um veredito.

O projeto foi desenvolvido com foco na utilização de **Python**, **Flet**, eventos, componentes gráficos e interação com o usuário.

---

## Objetivo

O objetivo da atividade foi desenvolver uma aplicação interativa utilizando Python e Flet, colocando em prática conceitos de programação e criação de interfaces gráficas.

Durante o desenvolvimento foram trabalhados:

- Criação de interfaces gráficas
- Funções
- Eventos
- Condicionais

- Interação com o usuário
- Atualização dinâmica da interface

---

## Investigação

A aplicação apresenta um caso de cibersegurança que deve ser analisado pelo usuário.

Durante a investigação, o usuário pode acessar diferentes informações e evidências para compreender o ocorrido e tomar uma decisão.

O sistema apresenta elementos como:

- Caso investigativo
- Linha do tempo
- Evidências
- Pistas
- Hipóteses
- Sistema de XP
- Dicas
- Veredito final

---

## Evidências

Durante a investigação, o usuário pode acessar diferentes evidências disponíveis no sistema.

Cada evidência apresenta informações que podem ajudar na resolução do caso.

Ao investigar novas evidências, o usuário pode receber pontos de experiência, incentivando a análise completa das informações disponíveis.

---

## Sistema de XP

O projeto possui um sistema de experiência utilizado para acompanhar o progresso do investigador.

A investigação de novas evidências pode adicionar XP ao jogador.

O sistema também utiliza a pontuação para permitir o acesso a dicas durante a investigação.

---

## Sistema de Dicas

Durante o caso, o usuário pode utilizar uma dica para auxiliar na investigação.

As dicas servem como apoio para analisar as evidências e escolher uma hipótese com maior segurança.

---

## Hipóteses

Depois de analisar as evidências, o usuário deve escolher uma hipótese para o incidente investigado.

A escolha deve ser baseada nas informações encontradas durante a investigação.

---

## Veredito

Após escolher uma hipótese, o usuário pode confirmar sua decisão.

O sistema apresenta o resultado da investigação, podendo indicar se o caso foi resolvido ou se o veredito foi inconclusivo.

Também são apresentadas informações relacionadas ao resultado e à pontuação obtida durante a investigação.

 Como Executar
1. Instalar o Python

Verifique se o Python está instalado:

python --version
2. Instalar o Flet

No terminal, execute:

pip install flet
3. Clonar o repositório
git clone https://github.com/PaollaVeronez05/Cyber_Detective.git
4. Acessar a pasta do projeto
cd Cyber_Detective
cd cyber_detctive
5. Executar a aplicação
python cyber_detective.py
